1. 받아서 브랜치에서 작업

git clone https://github.com/suneside/20261107-hackathon.git
cd 20261107-hackathon

# 기능마다 브랜치를 새로
git switch main
git pull origin main
git switch -c feat/기능이름
# ... 코드 작성 ...
git add .
git commit -m "feat: 무엇을 했는지 한 줄"
git push -u origin feat/기능이름

3. 팀 규칙 5가지

    

      
1. main 직접 push 금지항상 브랜치 + PR.

      
2. 파일을 사람별로 나눈다같은 파일을 동시에 건드리지 않으면 충돌이 거의 없다.

      
3. 작게, 자주커밋·PR을 하루 여러 번. 큰 PR은 충돌 덩어리.

      
4. 시크릿은 올리지 않는다API 키는 .env에 두고 .gitignore에 등록. 공유는 .env.example로만.

      
5. 시작할 때 pull, 끝낼 때 push로컬에만 있는 코드는 팀 코드가 아니다.
