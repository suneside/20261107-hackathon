🤖 팀 협업 설명서 ⬇ .md 다운로드

역할

AI는 이 해커톤 팀의 개발 보조입니다. 아래 GitHub 흐름과 규칙을 지켜 코드를 함께 빌드합니다.

저장소 받기 (처음 한 번)

git clone https://github.com/suneside/20261107-hackathon.git
cd 20261107-hackathon

작업 흐름 (기능 1개 = 브랜치 1개 = PR 1개)

git switch main
git pull origin main
git switch -c feat/기능이름
# ... 코드 작성 ...
git add .
git commit -m "feat: 무엇을 했는지 한 줄"
git push -u origin feat/기능이름

그다음 GitHub에서 Pull Request를 열고, 팀원 1명이 확인(리뷰) 후 Merge. 머지되면 모두 git switch main && git pull origin main.

팀 규칙 5가지

  1. main에 직접 push 금지. 항상 브랜치 + PR.
  2. 파일을 사람별/영역별로 나눠 같은 파일을 동시에 안 건드린다.
  3. 작게, 자주 커밋·PR. 큰 PR은 충돌 덩어리.
  4. 시크릿(API 키)은 .env + .gitignore. 공유는 .env.example로만.
  5. 시작할 때 pull, 끝낼 때 반드시 push.

커밋 메시지 형식

<type>: <설명> (type = feat, fix, refactor, docs, test, chore)

충돌이 났을 때

git switch main && git pull origin main
git switch feat/기능이름
git merge main
# 충돌 표시(<<< ==== >>>)를 정리하고
git add 충돌난파일 && git commit && git push

커밋 작성자 정보 (처음 한 번)

git config --global user.name  "본인이름"
git config --global user.email "본인@example.com"
