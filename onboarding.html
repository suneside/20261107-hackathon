0준비물 확인

  • GitHub 계정 — 없으면 github.com/signup 가입 후 아이디를 팀장에게 전달.
  • Git 설치 — 아래 명령으로 버전이 나오면 설치됨.
git --version

macOS는 실행 시 자동 설치 안내가 뜹니다. Windows는 git-scm.com.

1내 정보 등록 (처음 한 번)

git config --global user.name  "본인이름"
git config --global user.email "본인@example.com"

GitHub 가입 이메일을 그대로. 커밋에 이 정보가 찍힙니다.

2저장소 받기

git clone https://github.com/suneside/20261107-hackathon.git
cd 20261107-hackathon

공개 저장소라 바로 clone됩니다. push 권한이 필요하면 팀장에게 Collaborator 초대를 요청하세요.

3내 브랜치에서 작업

기능 하나마다 브랜치를 새로. 이름 예: feat/login-ui

git switch main
git pull origin main
git switch -c feat/기능이름

# ... 코드 작성 ...

git add .
git commit -m "feat: 무엇을 했는지 한 줄"
git push -u origin feat/기능이름

4Pull Request 열고 합치기

  1. push 하면 GitHub에 Compare & pull request 버튼이 뜹니다. 클릭.
  2. 무엇을 했는지 적고 Create pull request.
  3. 팀원 1명이 Files changed 확인 후 Merge.
  4. 합쳐진 뒤 모두 최신화 ↓
git switch main
git pull origin main

5팀 규칙 숙지

1. main 직접 push 금지항상 브랜치 + PR.
2. 파일을 사람별로 나눈다같은 파일을 동시에 안 건드리면 충돌이 없다.
3. 작게, 자주 커밋·PR큰 PR은 충돌 덩어리.
4. 시크릿 금지API 키는 .env + .gitignore. 공유는 .env.example로만.
5. 시작 땐 pull, 끝날 땐 push로컬에만 있는 코드는 팀 코드가 아니다.
